David Vieira — CV & Portfolio

A simple, responsive personal CV and portfolio website built with HTML, CSS, and JavaScript.

The website presents my professional experience, skills, education, projects, and contact information, with my CV available as a downloadable PDF.

Live Website

The website is deployed using GitHub Pages.

GitHub Pages Deployment

This project is a static website and requires no build tools, frameworks, or backend.

To deploy it with GitHub Pages:

Push the project to the main branch of a GitHub repository.
Open the repository on GitHub.
Go to Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Select the main branch and / (root) folder.
Click Save.

GitHub will automatically build and publish the website.

Local Development

No installation or dependencies are required.

Simply open index.html in a web browser to view the website locally.

For a better development experience, you can also use a local development server such as VS Code's Live Server extension.
